# Fiber Liquidity M3 CKB Chain Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace fail-closed Loop Out CKB watcher stubs with real payout, claim, refund transaction identity persistence, CKB actor sending, and transaction tracing.

**Architecture:** Add durable per-swap chain transaction records, then make `CkbLiquidityChainWatcher` build transaction plans, persist identity before `SendTx`, and register `CkbTxTracer` callbacks that drive `LiquidityActorMessage` continuations. Existing `LiquidityActor` remains the owner of swap state; existing `CkbChainActor` remains the only runtime CKB send/trace boundary.

`LiquidityChainWatcher` is an async boundary. The actor must await watcher operations rather than blocking inside synchronous trait methods, because real funding, signing, send, and trace operations go through async actor/RPC calls.

**Tech Stack:** Rust 1.93, Ractor, CKB SDK/types, existing `CkbChainActor`, existing `CkbTxTracer`, RocksDB-backed `LiquidityStore`, cargo-nextest/cargo test.

```rust
#[derive(Debug, Clone)]
pub struct LoopOutPayoutTxPlan {
    pub swap_id: Hash256,
    pub transaction: ckb_types::core::TransactionView,
    pub tx_hash: Hash256,
    pub outpoint: packed::OutPoint,
}

impl LoopOutPayoutTxPlan {
    pub fn new(
        swap_id: Hash256,
        transaction: ckb_types::core::TransactionView,
        output_index: u32,
    ) -> Self {
        let tx_hash: Hash256 = transaction.hash().into();
        let outpoint = packed::OutPoint::new(transaction.hash(), output_index);
        Self {
            swap_id,
            transaction,
            tx_hash,
            outpoint,
        }
    }
}

#[derive(Debug, Clone)]
pub struct LoopOutClaimTxPlan {
    pub swap_id: Hash256,
    pub payout_outpoint: packed::OutPoint,
    pub payment_preimage: Hash256,
}

impl LoopOutClaimTxPlan {
    pub fn from_record(record: &LiquiditySwapRecord) -> Result<Self, LiquidityLoopOutError> {
        let claim = LoopOutClaimPlan::from_record(record)?;
        let payout_outpoint = record.onchain_outpoint.clone().ok_or_else(|| {
            LiquidityLoopOutError::Chain("cannot build claim without payout outpoint".to_string())
        })?;
        Ok(Self {
            swap_id: claim.swap_id,
            payout_outpoint,
            payment_preimage: claim.payment_preimage,
        })
    }
}

#[derive(Debug, Clone)]
pub struct LoopOutRefundTxPlan {
    pub swap_id: Hash256,
    pub payout_outpoint: packed::OutPoint,
    pub refund_after_lock_time: u64,
}

impl LoopOutRefundTxPlan {
    pub fn from_record(
        record: &LiquiditySwapRecord,
        current_lock_time: u64,
    ) -> Result<Self, LiquidityLoopOutError> {
        if current_lock_time < record.refund_after_lock_time {
            return Err(LiquidityLoopOutError::Chain(
                "cannot refund loop out payout before refund lock time".to_string(),
            ));
        }
        let payout_outpoint = record.onchain_outpoint.clone().ok_or_else(|| {
            LiquidityLoopOutError::Chain("cannot build refund without payout outpoint".to_string())
        })?;
        Ok(Self {
            swap_id: record.swap_id,
            payout_outpoint,
            refund_after_lock_time: record.refund_after_lock_time,
        })
    }
}
```

Add `async fn send_and_trace` on `CkbLiquidityChainWatcher`:

```rust
async fn send_and_trace(
    &self,
    swap_id: Hash256,
    role: fiber_types::LiquidityChainTxRole,
    transaction: ckb_types::core::TransactionView,
    liquidity_actor: ActorRef<LiquidityActorMessage>,
) -> Result<(), LiquidityLoopOutError> {
    let tx_hash: Hash256 = transaction.hash().into();
    ractor::call!(self.ckb_chain_actor, |reply| {
        CkbChainMessage::SendTx(transaction.clone(), reply)
    })
    .map_err(|error| LiquidityLoopOutError::Chain(error.to_string()))?
    .map_err(|error| LiquidityLoopOutError::Chain(error.to_string()))?;

    let callback = Self::tracer_callback_for(swap_id, role, liquidity_actor);
    self.ckb_chain_actor
        .send_message(CkbChainMessage::CreateTxTracer(crate::ckb::CkbTxTracer {
            tx_hash,
            confirmations: 1,
            mask: crate::ckb::CkbTxTracingMask::Committed,
            callback,
        }))
        .map_err(|error| LiquidityLoopOutError::Chain(error.to_string()))?;
    Ok(())
}
```

Implement `tracer_callback_for` so committed payout/claim/refund results send `PayoutConfirmed`, `ClaimConfirmed`, or `RefundConfirmed`. Rejected results should be handled in later status-update tasks; do not mark success on rejected/unknown statuses.
